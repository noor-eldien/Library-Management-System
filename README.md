# Library-Management-System

## Overview  
A Java GUI application that simulates a library management system with different types of library items (books, eBooks, CDs, DVDs, etc.). The system allows users to add items, borrow/return items, and view available items through an interactive graphical interface.

## Features  

- **Item Management:** Supports 6 item types (Physical Books, eBooks, Reference Books, CDs, DVDs, Journals)  
- **Borrowing System:** Implements different borrowing rules per item type, preventing non-borrowable items from beign borrowed
- **User Management:** Tracks user borrowing history  
- **GUI Interface:** Interactive forms for all operations  
- **Inventory Tracking:** Maintains available quantities of each item  

## System Operations  
The program provides these GUI operations:  
1. **Add Item**  
2. **List Available Items**  
3. **Borrow Item**  
4. **Return Item**
